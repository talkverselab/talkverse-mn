# 회화(다이얼로그) — 몽골어 특이점

**공통 원칙은 https://talkverse.uk/talkverse/dialogue-rules/ 를 따른다**(레벨 = 절벽 R1~R4, 턴 수, 한글 독음 필수, 반전 1회, 수위 12+, 변이는 별도 파일, 검수 = 자동 검사 + Grok·Gemini 교차). 절벽 기준표 https://talkverse.uk/cliff/18/ .
이 문서에는 몽골어에만 해당하는 것만 적는다.

## 기본 변이
- 할흐 몽골어(울란바토르 표준), **키릴 문자**. 내몽골(전통 문자)·방언은 넣지 않는다 — 넣게 되면 공통 원칙대로 별도 파일.

## 한글 독음(`rd`) 표기
- 기준 표: `db/notes/mn_ko_transcription.md`, 적용은 `scripts/normalize_pron.py`(결정론 — 손으로 고치지 말고 규칙·스크립트를 고친다).
- 모음: **о=어, у=오, ө=으, ү=우**(학술 표준 대응). 구어 발음 우선(들리는 대로), 강세·장단 생략.

## 턴 길이
- 키릴 기준 한 턴 **7단어 이하**를 기본으로(지금 회화 최대 7). 몽골어는 어순이 한국어와 같고(SOV) 격 어미가 조사와 1:1 이라 한국어 뜻과 어순을 맞춰 쓴다.

## 성별판 · 음성
- 인물: A 민(한국인 학습자, 남) · B 사라(몽골 현지인, 여). 존대(Та)로 시작해 친해지면 반말(Чи).
- 기기 TTS 에 몽골어가 없어 **사전 합성 mp3** 를 쓴다(`scripts/tts_build.py`, Azure mn-MN). 지금은 여성 음성 하나(`mn-MN-YesuiNeural`)로 두 화자를 모두 읽는다 — 성별판을 나누면 남성 `mn-MN-BataaNeural` 로 A 를 따로 합성.

## 반전 비율 기준 (사용자 지시 2026-11-03, 모든 언어앱 공통 — 회화 작업이 풀리면 적용)
- **카오스**(일이 걷잡을 수 없이 커지는 반전) 전체의 **30% 이상**. 기존 편은 끝 2~4턴만 고쳐 카오스로, 바뀐 쌍의 컷만 다시 그린다.
- **심쿵**: 연애·플러팅 편은 편마다 심쿵 한 줄(마음을 들키는 말·말끝 흐리기·여운), 다른 주제에도 가끔. 여성이 먼저 다가가는 편을 더 많이.
- 편마다 `twist_type`: `chaos` · `slip` · `reveal` · `emotion` · `ignore` — 묶음마다 비율 확인.
- 새 편은 왕초보·초급 위주. 그림 = A·B 쌍 1컷(말풍선·글자 없음), 요청 때 인물 기준 그림(주인공+조연, `data/review/art/chars_mn_v1.jpg`) 첨부.
- 참고 구현: 한국어앱 `~/talkverse/ko/assets/data/dialogues/`, 반전 고친 예 커밋 `a2e8eb9`.
- 몽골어 메모: 지금 2편(L1)은 `twist` 만 있고 `twist_type` 없음 — 회화 작업 때 태그·비율을 맞춘다. Grok 재작성 뒤 Gemini 검수(`CHARACTERS.md` 끝 메모).
