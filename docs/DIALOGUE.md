# 회화(다이얼로그) — 몽골어 특이점

**공통 원칙은 https://talkverse.uk/talkverse/dialogue-rules/ 를 따른다**(레벨 = 절벽 R1~R4, 턴 수, 한글 독음 필수, 반전 1회, 수위 12+, 변이는 별도 파일, 검수 = 자동 검사 + Grok·Gemini 교차). 절벽 기준표 https://talkverse.uk/cliff/18/ .
이 문서에는 몽골어에만 해당하는 것만 적는다.

## 기본 변이
- 할흐 몽골어(울란바토르 표준), **키릴 문자**. 내몽골(전통 문자)·방언은 넣지 않는다 — 넣게 되면 공통 원칙대로 별도 파일.

## 한글 독음(`rd`) 표기
- 기준 표: `db/notes/mn_ko_transcription.md`, 적용은 `scripts/normalize_pron.py`(결정론 — 손으로 고치지 말고 규칙·스크립트를 고친다).
- 모음: **о=어, у=오, ө=으, ү=우**(학술 표준 대응). 구어 발음 우선(들리는 대로), 강세·장단 생략.

## 턴 길이
- 키릴 기준 한 턴 **7단어 이하**를 기본으로(지금 회화 최대 7). 몽골어는 어순이 한국어와 같고(SOV) 격 어미가 조사와 1:1 이라 한국어 뜻과 어순을 맞춰 쓴다.

## 성별판 · 음성
- 인물: A 민(한국인 학습자, 남) · B 사라(몽골 현지인, 여). 존대(Та)로 시작해 친해지면 반말(Чи).
- 기기 TTS 에 몽골어가 없어 **사전 합성 mp3** 를 쓴다(`scripts/tts_build.py`, Azure mn-MN). 지금은 여성 음성 하나(`mn-MN-YesuiNeural`)로 두 화자를 모두 읽는다 — 성별판을 나누면 남성 `mn-MN-BataaNeural` 로 A 를 따로 합성.

## 지금 상태 (2026-11-02)
- `app/assets/data/dialogues/L1.json`: 2편 × 8턴(옛 L1 = 새 R1). 공통 원칙의 레벨 이름(R1~R4)·반전 표시로 바꾸는 일은 아직 안 함.

## 반전 비율 기준 (사용자 지시 2026-11-03, 모든 언어앱 공통 — 회화 작업이 풀리면 적용)
- **카오스**(일이 걷잡을 수 없이 커지는 반전) 전체의 **30% 이상**. 기존 편은 끝 2~4턴만 고쳐 카오스로, 바뀐 쌍의 컷만 다시 그린다.
- **심쿵**: 연애·플러팅 편은 편마다 심쿵 한 줄(마음을 들키는 말·말끝 흐리기·여운), 다른 주제에도 가끔. 여성이 먼저 다가가는 편을 더 많이.
- 편마다 `twist_type`: `chaos` · `slip` · `reveal` · `emotion` · `ignore` — 묶음마다 비율 확인.
- 새 편은 왕초보·초급 위주. 그림 = A·B 쌍 1컷(말풍선·글자 없음), 요청 때 인물 기준 그림(주인공+조연, `data/review/art/chars_mn_v1.jpg`) 첨부.
- 참고 구현: 한국어앱 `~/talkverse/ko/assets/data/dialogues/`, 반전 고친 예 커밋 `a2e8eb9`.
- 몽골어 메모: 지금 2편(L1)은 `twist` 만 있고 `twist_type` 없음 — 회화 작업 때 태그·비율을 맞춘다. Grok 재작성 뒤 Gemini 검수(`CHARACTERS.md` 끝 메모).

## 작성 흐름·구성 (2026-11-07 회화 작성 제한 해제, 사용자 지시)
- 흐름: Claude 초안 → Grok 재작성 → Gemini 검수(`~/talkverse/GEMINI_REVIEW_GUIDE.md`). 초안은 `app/assets/data/dialogues/R<레벨>/<주제>/<편id>.json`, `draft: true`. 앱에는 아직 안 실림(`pubspec` 의 폴더 등록이 하위 폴더를 포함하지 않고 로더도 `L1.json` 만 읽음) — 검수가 끝나면 로더를 옮긴다. 회화 밖 콘텐츠 동결은 그대로.
- 150편 = R1 90(서바이벌 6·사랑 24·친구 18·생활 18·여행 18·문화 6) · R2 36(사랑 12·친구 6·생활 6·여행 6·일 6) · R3 24(사랑 6·친구 4·생활 4·여행 4·일 3·문화 3). 턴 R1 6~8 · R2 8~12 · R3 12~16, 한 턴 낱말 R1 ≤7 · R2 ≤9 · R3 ≤12.
- 절벽 R1 이 49어(접사 포함)라 「구간 단어만」은 회화가 안 된다 → 구간 어휘는 막지 않고 통계로만 본다. 레벨은 문장 길이·문형 난이도로 나눈다.
- 턴마다 `emotion`(값 16개 = `~/talkverse/ja/data/tts/PLAN_GUIDE.md`, 사용자 지시 2026-11-07). 한 턴에서 감정이 바뀌면 `segs` = [[감정, 본문], …], 이어 붙이면 `tl` 과 같아야 함. neutral 만 쓰지 말 것.
- 음성 감정 계획: `tools/tts/build_plan.py` → `data/tts/plan/<편id>.json`. 생성기는 몽골어 음성 모델이 정해진 뒤 이 계획을 읽게 쓴다.
- 2026-11-08 Claude 초안 150편 완료(R1 90 · R2 36 · R3 24, 카오스 51 = 34%). 작성 규칙 `tools/prompts/dialogue_mn.md`. 목적 태그는 travel · study_abroad · work_mongolia · media · love · making_friends. Grok 재작성 때 겹치는 농담 정리: 단톡방 하트(r1_love_c3·r1_travel_c2), 「네」만 하다 일이 커짐(r1_survival_a1·r1_travel_a2·r2_life_b1), 끝없는 세배 줄(r1_culture_a1·r2_love_b5), 비슷한 단어 말실수(хурга·шүүс·үс·уйлдаг·өвдөж).
- 도구: `tools/check_dialogues.py --fix-rd --report`, 표현 풀 `data/expressions/mn_top_expressions.csv`.

## Grok 재작성·장면 컷 요청문 (2026-11-03, 중국어앱 정리 — 회화 작업 때)
- 작성법 `~/talkverse/GROK_PROMPT_GUIDE.md`, 틀 `~/talkverse/zh/tools/`(prompts/rewrite_grok.md·rewrite_request.py·scene_prompts.py·grok_*.py) 복사 후 코드만 mn 으로.
- 요점: 전문가 모델, 편마다 새 대화방, 답은 30초 뒤 다시 받기 / 재작성 = 판정 말고 재작성, 카오스·재미·심쿵을 맨 위에, 모든 줄 새로(유지 금지), 한 줄 출력 형식 고정 / 받은 재작성은 리뷰 후 반영 / 컷 = 캐릭터 시트+시안 첨부, 조연 외모 고정, 글자 없는 간판, 컷마다 한 요청, 접촉 시트로 리뷰.
