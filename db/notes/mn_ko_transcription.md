# 몽골 키릴 → 한글 독음 규칙 (SOT)

> 앱 `pron` 필드의 단일 기준. 학습용 근사 표기(정밀 IPA 아님).
> 원칙: ① 소리 우선 ② 일관성 ③ 한국어로 읽기 쉽게. 강세·장단은 생략.
> **구현**: `scripts/normalize_pron.py` 가 이 규칙을 결정론적으로 적용해
> `app/assets/data/travel/*.json` 의 `pron` 을 mn 에서 생성한다(= 실제 SOT).
> 규칙을 바꾸려면 스크립트의 표를 고치고 `python normalize_pron.py --write` 재실행.
> (장모음은 1회로 축약: уу→오, өө→어, ээ→에. 폐쇄음 г/к/б/п는 어말=받침, 자음앞=음절 그/크/브/프.)

## 1. 모음

| 키릴 | 한글 | 메모 |
|---|---|---|
| а | 아 | 남성(후설) |
| э | 에 | 여성(전설) |
| и | 이 | 중성 |
| о | 오 | 남성 |
| ө | 어 | ⚠ 여성. 입술 둥근 [ö]. '으'가 아니라 '어'로 통일 |
| у | 오 | 남성. 한국어 'ㅗ'에 가까움 (예: ус 오스) |
| ү | 우 | ⚠ 여성. [ü]. 한국어 'ㅜ'로 통일 |
| е | 예 | 어두/단독 '예' (단어 중간은 '에') |
| ё | 요 | |
| ю | 유 | |
| я | 야 | |
| ы | 이 | 어말 -ы는 '이' (깊은 '으이'지만 '이'로 통일) |

**장모음(겹모음)**: аа/ээ/оо/өө/уу/үү 는 단모음과 같은 글자로 적되 길게. 독음은 단모음과 동일 표기(아/에/오/어/오/우). 과도한 '一' 금지.

**이중모음**: ай 아이 · ой 오이 · эй 에이 · уй 오이.

## 5. 주의(현재 데이터에서 흔한 오류)
- `ө`를 '으'로 적은 곳 → **'어'로 통일** (өдөр 우두르 ❌ → 어두르 ✅, мөнгө 멍거).
- `ү`를 '위'로 적은 곳 → 문맥상 '우'로 통일 가능(үнэхээр 우네헤르).
- 어말 `н`을 'ㄴ'으로 → **받침 ㅇ** (훈 ❌ → 훙 ✅).
- `в`를 'ㅂ'으로 → 모음 사이/어말은 '우'(w).
